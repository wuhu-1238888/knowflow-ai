## 2. 交互检查(约 5 分钟)

1. **无策略切换入口**:页头只有标题「知识问答」,页面上不出现「向量 / 混合 / 混合+重排」字样或任何检索策略选择器(2026-09-09 人拍板)
2. **键盘**:输入框按 Enter → 提交;Shift+Enter → 换行不提交;任意位置按 `/` → 聚焦输入框
3. **示例 chip**:点「年假有几天?」→ 输入框自动填入并立即提交
4. **按钮状态**:输入框为空时「提问」按钮禁用;提交后加载中按钮禁用
5. **复制回答**:点击后粘贴板得到回答正文

## 5. 视觉与无障碍(DesignRules 硬规则)

- **375px 窄屏**:无横向滚动条(scrollWidth ≤ clientWidth);评测页表格在容器内滚动
- **焦点环**:Tab 走查按钮/输入框 → 2px 品牌紫描边 + 2px 偏移
- **动效**:仅 hover ≤150ms 颜色过渡;「AI 生成中」胶囊呼吸动画 1.6s(白名单唯一无限循环)
- **渐变白名单**:页面仅 3 处渐变(侧栏品牌标记 / 回答卡 AI 眉题 8px 圆点 / 生成中胶囊)
- **每屏一个 primary**:问答页只有「提问」;重试/复制/示例均为次级;评测页暂无 primary(运行按钮属 3.3.4)
- **数字全 mono**;无 emoji 图标;无聊天流/气泡布局

## 6. 判定标准

- **Blocker(不通过,当场修复)**:提问白屏/500/无响应;引用片段与来源原文对不上;拒答卡出现红色或感叹号;375px 横向溢出;primary 按钮多于一个;**问答页出现检索策略切换入口或工程调试值(最高分/耗时/阈值)**
- **样式打磨类(记遗留,不阻塞)**:间距/字号微调
- **已知非缺陷,勿当 bug 报**:冲突面板不出现(Mock conflicts 恒 null → 遗留 #1);点击引用无联动、无来源抽屉(3.3.2 全量未做);评测页为静态快照(运行按钮/历史/动态数据在 3.3.4);文档库/关于页仍是空状态(3.3.3/3.3.5 未开始)

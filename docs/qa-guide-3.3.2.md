## 2. 交互检查(约 8 分钟)

1. **无策略切换入口**:页头只有标题「知识问答」与一行克制副标题「企业知识助手,基于企业知识库回答问题」,页面上不出现「向量 / 混合 / 混合+重排」字样或任何检索策略选择器(2026-09-09 人拍板)
2. **键盘**:输入框按 Enter → 提交;Shift+Enter → 换行不提交;任意位置按 `/` → 聚焦输入框
3. **示例 chip**:点「年假有几天?」→ 输入框自动填入并立即提交
4. **按钮状态**:输入框为空时「提问」按钮禁用;提交后加载中按钮禁用
5. **复制回答**:点击后粘贴板得到回答正文
6. **依据条目(EvidenceItem)**:每条依据 = [n] 编号 chip + 文档标题 + 格式·上传时间 + 引用片段(灰底 + 左侧浅蓝边线)+ 来源徽标(混合/向量/关键词)+ 相关度分数(mono 2 位小数)+「查看原文」
7. **来源抽屉(SourceDrawer)**:点「查看原文」→ 右侧 360px 抽屉滑入(200ms,遮罩 0.16):文档标题 20px、格式徽标·状态徽标(已索引/解析中/解析失败)·上传时间、完整 chunk 原文(可滚动)、相关度分数与来源模式、「在文档库中查看」链接;按 Esc 或点遮罩关闭
8. **重新生成(FR-11)**:回答完成后点「重新生成」→ 上方出现「AI 生成中」胶囊,**旧回答仍可见**;完成后新回答在上、旧回答在下堆叠
9. **有用·无用(FR-12)**:点「有用」或「无用」→ 按钮文字变品牌深蓝并保持选中;再次点另一项 → 切换选中(后端同一条 QA 记录覆盖保存)。注:提交失败时按钮静默回退为未选中(暂无提示组件,记遗留)
10. **引用 chip 内嵌与双向联动(注意预期)**:回答正文内的 `[n]` 方形 chip、悬停 chip ↔ 引用句高亮 ↔ 依据条目描边联动,**依赖回答正文含 [n] 编号标记**。当前 Mock Provider 逐字摘录原文、不带编号 → **实测页面上不出现内嵌 chip,双向联动暂不可手测**(已由 L3 组件测试用固定夹具覆盖,真实 LLM 到位后自然呈现);若看到回答中有 `[n]` 灰态 chip = 编号超出依据带,属保护性提示,非缺陷

## 5. 视觉与无障碍(DesignRules 硬规则)

- **375px 窄屏**:无横向滚动条(scrollWidth ≤ clientWidth);评测页表格在容器内滚动;来源抽屉 360px ≤ 屏宽、不溢出
- **焦点环**:Tab 走查按钮/输入框/引用 chip → 2px 品牌蓝描边 + 2px 偏移
- **动效**:hover ≤150ms 颜色过渡;抽屉滑入 200ms(motion.medium,白名单内);「AI 生成中」胶囊呼吸 1.6s(唯一无限循环)
- **渐变白名单**:页面仅 3 处渐变(侧栏品牌标记 / 回答卡 AI 眉题 8px 圆点 / 生成中胶囊)
- **每屏一个 primary**:问答页只有「提问」;重新生成(secondary)/复制/查看原文/有用·无用均为次级
- **数字全 mono**;无 emoji 图标;无聊天流/气泡布局
- **容器宽度(2026-09-09 人拍板)**:问答 960 / 评测·文档库 1152 / 关于 880,均居中;1920px 下 max-width 封顶不拉伸;页内区块(页头/输入区/卡片/表格)统一容器宽度
- **垂直节奏(2026-09-09 人拍板,仅问答页)**:主内容顶部呼吸空间 24px(<1024px)/48px(≥1024px);页头 → 输入区 24px;各状态区块间统一 24px,加载/空态/回答/拒答/错误同位不跳动;首屏即可见提问框,无 Hero 式大留白

## 6. 判定标准

- **Blocker(不通过,当场修复)**:提问白屏/500/无响应;引用片段与来源原文对不上;拒答卡出现红色或感叹号;375px 横向溢出;primary 按钮多于一个;**问答页出现检索策略切换入口或工程调试值(最高分/耗时/阈值)**;来源抽屉内原文与依据片段对不上;重新生成后旧回答消失
- **样式打磨类(记遗留,不阻塞)**:间距/字号微调
- **已知非缺陷,勿当 bug 报**:冲突面板不出现(Mock conflicts 恒 null → 遗留 #1);回答正文无内嵌 [n] chip 与双向联动(Mock 不带编号,见交互检查第 10 条,真实 LLM 到位后自然呈现);评测页为静态快照(运行按钮/历史/动态数据在 3.3.4);文档库/关于页仍是空状态(3.3.3/3.3.5 未开始)

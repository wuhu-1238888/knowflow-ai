# QA Guide 3.6.2:核心功能闭环优化——L4 走查指引

> 版本:v0.1 | 日期:2026-09-13
> 适用:浏览器 http://localhost:3001(前端 3001 + 后端 8000)
> 目的:为「核心功能闭环优化」30 节规格提供人工走查步骤;自动化已覆盖部分(后端 pytest 198、前端 vitest 183),本节聚焦**必须亲眼看一遍**的界面行为。
> 前置:dev server 已启动;知识库为 NovaTech synthetic demo data(synthetic: true)。

## 1. 文档详情页(/documents → 点任一文档标题)

| # | 步骤 | 预期 |
| --- | --- | --- |
| 1.1 | 点「员工手册.md」标题 | 进入详情页;基本信息含格式/状态/上传时间/分块数 |
| 1.2 | 看「内容预览」 | 显示源文件开头片段,可滚动;高度约 320px 不撑爆页面 |
| 1.3 | 看「分块内容」列表 | 每块带「Chunk 1/2/…」序号 + 标题(如「# 第一章 入职」)或首行摘要 |
| 1.4 | 点「返回文档库」 | 回到列表页 |

**失败态走查**:先在列表页上传一个空 .md(会解析失败)→ 详情页应显示「解析失败」徽标 + 失败原因行 +「暂无预览(文档解析失败或源文件缺失)」+ 空分块列表。

## 2. 来源抽屉定位(问「年假有几天?」→ 回答带引用)

| # | 步骤 | 预期 |
| --- | --- | --- |
| 2.1 | 依据条目点「查看原文」 | 抽屉滑入;引用片段在原文中**黄色高亮**(mark) |
| 2.2 | 看高亮上方提示 | 「回答引用的片段已在原文中高亮」 |
| 2.3 | 点「在文档库中查看」 | 跳到**该文档的详情页**(不再是列表页伪链接) |
| 2.4 | 校验一致性 | 抽屉原文 ⊇ 依据片段;详情页分块列表含同一 chunk |

## 3. 拒答两态(评测集 C11/C13)

| # | 步骤 | 预期 |
| --- | --- | --- |
| 3.1 | 问「公司有宠物寄养福利吗?」(无相关) | 拒答卡:「未找到答案」+「依据 0 条」 |
| 3.2 | 问「公司有健身房吗?」(信息不足) | 拒答卡变体:「找到相关信息,但不足以确定答案」+「找到相关信息 N 条,置信度不足」,**无 AI 回答正文** |

> 注:3.2 依赖知识库中存在低分相关内容;若无,视为拒答第一态,同样达标。

## 4. 会话历史「最近问过」

| # | 步骤 | 预期 |
| --- | --- | --- |
| 4.1 | 连续问 3 个不同问题 | 结果区下方出现「最近问过」列表,最近的在最前 |
| 4.2 | 点一个旧问题 | 问题文本回到输入框,结果区还原当时回答/依据,**不出现加载态、不发新请求**(快) |
| 4.3 | 对当前问题点「重新生成」 | 完成后历史条目更新为最新快照,不新增重复条目 |
| 4.4 | 问超过 6 个问题 | 列表保持 6 条,最早的被挤出 |
| 4.5 | 刷新浏览器 | 「最近问过」清空(仅当前会话,属预期) |

## 5. 文档库提示与失败恢复

| # | 步骤 | 预期 |
| --- | --- | --- |
| 5.1 | 删除一篇文档 | 出现「已删除「标题」,该文档不再参与检索」提示,约 3 秒自动消失 |
| 5.2 | 对 indexed 文档点「重建索引」 | 出现「已重建索引:标题」提示,3 秒自动消失 |
| 5.3 | 删除后立即问该文档内容 | 拒答或不再引用该文档(FR-09) |
| 5.4 | 重索引后问新内容 | 新内容可被检索(重索引真实更新) |

## 6. 处理状态与失败重试

| # | 步骤 | 预期 |
| --- | --- | --- |
| 6.1 | 上传一个正常 .md | 列表行内「上传解析中…」→ 刷新后「已索引」 |
| 6.2 | 上传空 .md | 状态「解析失败」徽标;鼠标悬停显示失败原因 |
| 6.3 | 对 failed 文档点「重建索引」 | 若源文件仍无效 → 再次 failed 并保留失败原因;若已修复 → 变 indexed |

## 7. 评测页视觉层级

| # | 步骤 | 预期 |
| --- | --- | --- |
| 7.1 | 打开评测页看一条运行历史 | 第一眼 = 策略名 + 状态徽标 + 时间 + **核心指标(宏平均/MRR 等)**;run_id/params/commit 在第二行小字(caption) |
| 7.2 | 展开看逐例明细 | 指标表格优先,参数为辅助信息 |

## 8. 回归抽查(防破坏)

| # | 步骤 | 预期 |
| --- | --- | --- |
| 8.1 | 问「年假有几天?」 | 回答 + 依据与来源 + 有用/无用反馈 + 复制(✓已复制) |

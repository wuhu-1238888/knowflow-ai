# NovaTech 会议纪要模板

> 版本:2026-01 | 适用对象:全体会议组织者

## 模板结构

```
会议主题:{主题}
时间 / 地点:{YYYY-MM-DD HH:MM,会议室或线上}
参会人:{姓名}
记录人:{姓名}

一、结论
1. {已拍板的决定}

二、待办
| 事项 | 负责人 | 截止时间 |
| --- | --- | --- |

三、未决问题
1. {留到下次讨论的问题}

四、下次会议:{时间与议题}
```

## 约定

- 会议结束后 24 小时内发出纪要,发送到参会人企业邮箱并归档到共享盘对应项目目录;
- 待办事项须有负责人与截止时间,不能只写"会后跟进";
- 跨部门会议纪要需同步抄送双方部门负责人。

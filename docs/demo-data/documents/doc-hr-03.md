# 差旅费用报销制度(2024 版)

> 发布:2024-03-01 | 适用对象:NovaTech 全体员工

## 市内交通费

- 员工因公产生的市内交通费(地铁、公交)实报实销。
- **每日报销上限为 100 元**,超出部分由员工自行承担。
- 打车费仅限特殊情况(携带设备、加班至 22:00 后),需在报销单中注明事由。

## 报销凭证

- 所有报销需保留原始票据(发票或电子行程单)。
- **报销凭证保留期限为 6 个月**,财务抽查时需能提供原件。
- 票据丢失需提供情况说明并由部门负责人签字。

## 报销流程

1. 在办公系统填写电子报销单,上传票据照片;
2. 部门负责人审批;
3. 财务复核后于当月工资日发放。

# 打印机与会议室设备使用说明

> 适用对象:全体员工 | 版本:2026-02

## 打印机

- 办公区每层设有一台共享打印机(3F 东侧、5F 西侧),支持彩打与双面打印。
- 电脑首次打印需安装驱动,驱动下载地址:`https://print.novatech.example.com/driver`。

### 打印机卡纸怎么办

1. **不要用力拉扯纸张**——按打印机面板上的「卡纸处理」按钮,让滚轮自动退纸;
2. 若自动退纸失败,打开前盖,沿出纸方向轻轻抽出卡住的纸张;
3. 检查纸盒:纸张受潮或放反会导致反复卡纸,换一叠新纸再试;
4. 取出全部纸屑后合上盖板,打印机会自动恢复待机;
5. 仍无法解决,联系 IT 服务台报修(报修时说明打印机位置与故障现象)。

### 打印队列与耗材

- 打印任务可在打印队列中取消:开始菜单搜索「打印机」→ 打开队列 → 右键取消;
- 缺墨、缺纸可直接到前台领用耗材,前台会登记。

## 会议室设备

- 会议室均配有投影或大屏,连接方式:HDMI 直连或无线投屏(投屏码在屏幕右上角);
- 视频会议使用会议平板自带的会议软件,账号与办公门户一致;
- 设备故障或遥控器没电,联系 IT 服务台,勿自行拆卸设备。

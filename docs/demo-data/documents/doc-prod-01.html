NovaFlow 云平台产品总览

版本:2026-07 | 适用对象:NovaTech 员工与客户

产品定位

NovaFlow 是 NovaTech 推出的企业级云平台,提供应用托管、数据管道与智能告警三大核心服务,帮助客户将业务系统平稳迁移上云并持续运行。

三大模块

  • 应用托管(App Hosting):支持容器化应用一键部署、自动扩缩容与灰度发布,托管运行时由 NovaCore 提供。
  • 数据管道(Data Pipeline):提供从数据接入、清洗到落库的流批一体处理能力,支持 SQL 与低代码两种开发方式。
  • 智能告警(Smart Alert):基于告警降噪与根因分析模型,将告警风暴压缩为可行动的工单,Project-X 项目即为该模块的内部代号。

部署方式

平台支持公有云部署与私有化部署两种形态。公有云版按用量计费;私有化版面向对数据驻留有要求的客户,由解决方案团队交付。

访问入口

员工与客户统一通过控制台(console.novatech.example.com)访问,登录使用 NF-ID 或客户专属账号体系。

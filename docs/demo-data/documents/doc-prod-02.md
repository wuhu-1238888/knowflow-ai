# NovaTech 内部术语表

> 版本:2026-08 修订 | 面向新员工,收录公司内部高频术语

## 平台与身份

- **NovaFlow**:NovaTech 的核心云平台产品,含应用托管、数据管道、智能告警三大模块。
- **NF-ID**:NovaFlow ID 的缩写,是公司内部的**统一身份标识**。一个 NF-ID 关联员工的企业账号,可登录办公门户、邮箱、VPN 与 NovaFlow 控制台等全部内部系统,实现单点登录。
- **NovaCore**:NovaFlow 平台的后端核心服务,负责容器调度、数据管道运行时与告警计算,是平台稳定性的关键组件。

## 研发流程

- **POD**:Publish On Demand 的缩写,即**按需发布流程**。POD 将代码发布拆解为「构建 → 灰度 → 全量」三个阶段,发布人凭工单按需触发,取代过去固定周发布的模式。新人参与发布的详细步骤见《发布流程(POD)》。
- **CCR**:Code Change Request,代码变更申请单,所有进入主干的代码改动必须先建 CCR 并关联需求。
- **灰度发布**:先向 5% 用户流量发布新版本,观察指标无异常后再逐步放量到 100% 的发布策略。

## 告警与运维

- **告警风暴**:同一故障引发大量重复告警的现象,智能告警模块的降噪能力即针对此问题。
- **SLO**:Service Level Objective,服务等级目标,例如「核心 API 月度可用性 ≥ 99.9%」。

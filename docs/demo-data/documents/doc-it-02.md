# NovaTech VPN 配置指南

> 适用对象:全体员工 | 版本:2026-03 修订

## 客户端下载

- **下载地址:`https://vpn.novatech.example.com/client`**,使用企业账号(NF-ID)登录后选择对应操作系统版本下载。
- 支持 Windows、macOS、Linux 与移动端(iOS/Android)。
- 客户端版本需保持最新,旧版本将在停服窗口期后被强制下线。

## 连接配置

1. 安装客户端后,打开软件填写服务器地址:`vpn.novatech.example.com`;
2. 用户名使用企业账号,密码为办公门户密码;
3. 首次连接需完成手机验证码二次验证(每 30 天一次);
4. 连接成功后即可访问内网系统,包括共享盘、办公门户与测试环境。

## 常见问题

- **连不上**:先确认已连接外网,再检查客户端是否为最新版本;仍失败请联系 IT 服务台并提供错误码。
- **异地办公**:VPN 允许跨地区接入,但连续 3 天以上远程办公需按《员工手册》申请远程办公。
- **断开后重连**:客户端会自动重连,无需重复输入密码;若提示密码错误,请走「找回密码」流程。

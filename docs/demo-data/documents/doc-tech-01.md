# NovaFlow 测试环境部署手册

> 版本:2026-05 | 适用对象:研发人员

## 准备

- 安装 Docker(24+)与 kubectl,并申请测试集群访问权限(按《账号申请与密码》流程申请);
- 代码仓库统一使用主干分支的最新代码,部署前先在本地跑通单测。

## 部署步骤

1. 克隆仓库并切换到对应服务的目录;
2. 执行 `make build` 构建镜像,构建产物推送到内部镜像仓库;
3. 更新部署清单中的镜像 tag,执行 `kubectl apply -f deploy/test/` 部署到测试集群;
4. 执行 `kubectl rollout status` 确认滚动更新完成;
5. 在测试环境控制台完成冒烟验证:登录、创建应用、跑一条示例数据管道。

## 回滚

- 部署异常时先执行 `kubectl rollout undo` 回滚到上一个版本,再排查原因;
- 回滚后必须在 CCR 中记录回滚原因与修复计划。

## 注意事项

- 测试集群资源有限,大镜像请先压缩(建议镜像 < 500MB);
- 部署失败不要反复重试,连续失败两次即联系平台研发部值班同事。

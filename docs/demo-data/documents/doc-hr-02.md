# 新员工入职 Checklist

> 适用对象:入职第 1–2 周的新员工 | 版本:2026-07 修订

## 第一周必须完成的事项

1. **Day 1(报到日)**:
   - 到人事行政部办理入职手续,提交身份证、银行卡复印件,签署劳动合同;
   - 领取工牌、门禁卡与办公设备(笔记本电脑、显示器);
   - 认识带教导师,加入部门与企业微信大群。
2. **Day 1–2(IT 账号)**:
   - 按 IT 部门指引完成企业账号开通与密码修改(详见《账号申请与密码》);
   - 配置 VPN 客户端与公司邮箱,加入部门共享盘;
   - 完成信息安全培训在线课程并通过考试。
3. **Day 3–5(制度与培训)**:
   - 阅读《员工手册》《请假制度》《差旅费用报销制度(2026 版)》;
   - 参加新人培训:公司文化、NovaFlow 产品总览、代码规范与发布流程;
   - 在 NovaFlow 控制台申请开发者权限,完成第一个示例项目部署。

## 第二周建议完成

- 与带教导师结对完成一次代码走查;
- 参加一次部门周会并提交会议纪要;
- 熟悉《术语表》,掌握 NF-ID、POD 等内部常用概念。

## 注意事项

- 入职第 1 周事项如未完成,请及时联系带教导师或 IT 服务台协助,不要拖延到第二周。

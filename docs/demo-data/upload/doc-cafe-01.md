# NovaTech 办公室咖啡吧使用规范

> 版本:2026-07 | 适用对象:NovaTech 全体员工与访客

## 位置与开放时间

- 咖啡吧位于总部 3 楼东侧茶水间,工作日 08:30–18:30 开放。
- 访客可凭前台发放的访客卡取用饮品。

## 饮品与收费

- 咖啡(意式浓缩 / 美式 / 拿铁)工作日全天免费供应,无限续杯。
- 茶叶(红茶 / 绿茶 / 乌龙)与橙汁免费供应。
- 瓶装气泡水按成本价 5 元/瓶 收取,扫码支付。

## 自带杯环保积分

- 使用自带杯取用咖啡,每杯奖励 1 元环保积分。
- 积分按季度兑换环保礼品(布袋 / 保温杯 / 绿植)。

## 使用礼仪

- 用毕请清洁杯具并放回消毒柜;奶泡罐每周五 18:00 统一深度消毒。
- 高峰时段(09:00–09:30)每人限取 2 杯,请勿代排队同事囤杯。
- 咖啡豆由「晨光烘焙」每周一上午配送,如发现豆仓余量不足请在企业微信联系行政部。

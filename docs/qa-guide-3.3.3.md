# 文档库页(3.3.3)测试验收指引

> 版本:v0.1 | 2026-09-09
> 适用:任务 3.3.3 文档库页(上传/列表/删除/重建索引)L4 手工走查与切片验收
> 口径:所有预期值来自实测(后端 pytest 141 例、前端 vitest 114 例、双链路 curl 实测),不虚构;验收结论以本指引亲测为准。

## 0. 环境与前置(约 1 分钟)

- 前端 3001、后端 8000 均已运行。检查:`curl http://127.0.0.1:8000/health` → `{"status":"ok"}`;浏览器打开 http://localhost:3001/documents
- 知识库已装载 20 篇 NovaTech 演示文档(synthetic:true,72 chunks);上传的文档落 `runtime/uploads/`,synthetic=false
- 准备一个测试用 `.md` 文件(内容随意,如两行正文)与一个 `.png` 文件(测格式拒绝)

## 1. 列表检查(约 2 分钟)

1. **20 篇演示文档全部呈现**:标题 / 格式徽标(MD/PDF/DOCX/HTML/TXT)/ 状态徽标(已索引,success 绿底)/ 分块数(>0,mono 右对齐)/ 上传时间(YYYY-MM-DD)/ 操作列(重建索引 + 删除两个图标按钮);表格底部「共 20 篇文档」
2. **表格 token**:表头 surface-2 底、行间 hairline 分隔线、行 hover 浅灰(surface-2,150ms)
3. **页面结构**:页头 64px 标题「文档库」+ 右侧 primary「上传文档」(本页唯一 primary);下方上传区;再下方表格

## 2. 上传检查(约 3 分钟)

1. **点击上传区或「上传文档」→ 文件选择框**,只允许 .md/.pdf/.docx/.html/.txt(accept 过滤)
2. **拖拽 `.md` 文件进上传区 → 立即出乐观行**:表格首行出现文件名 + 「上传解析中…」+ 格式徽标 + 状态徽标「待索引」(neutral)+ 分块数/时间「—」;**无全局遮罩、无整页 loading**;「上传文档」按钮与上传区禁用
3. 解析+索引完成(数秒)→ 乐观行消失,列表刷新:该文档变为「已索引」,分块数 > 0,「共 21 篇文档」,上传时间 = 今天
4. **格式拒绝**:拖拽 `.png` → 上传区下方红色 caption(role=alert)「暂不支持 .png 格式,支持 .md .pdf .docx .html .txt」,**不发请求、无乐观行**
5. **解析失败分支(可选)**:上传一个内容为 `<!-- 仅注释 -->` 的 `.html` 文件 → 上传区下方显示「文件解析失败:…」错误提示,同时列表刷新出一条「解析失败」(danger)行——该行是后端落库的 failed 记录,供重建索引重试
6. **无 OCR 说明**:上传区内有「不支持 OCR,扫描件请先转文本」caption

## 3. 删除检查(FR-09,约 3 分钟)

1. 点某行「删除」图标 → **danger 确认模态**:半透明遮罩 + 居中卡片(圆角 12px、浮动阴影),标题「删除文档」,描述「确定删除「{标题}」吗?删除后该文档将从知识库移除,检索不再命中,且不可恢复。」,按钮「取消」(secondary)+「确认删除」(danger 红底,此上下文唯一 primary)
2. **取消三通道**:点遮罩 / 按 Esc / 点「取消」→ 模态关闭,**文档仍在、计数不变**
3. **确认删除** → 模态关闭,列表刷新:该行消失,「共 N-1 篇文档」
4. **FR-09 核心**:删除某篇演示文档后回问答页,提一个原来命中该文档的问题(如删掉「员工手册」后问「年假有几天?」)→ 该依据不再出现(可能拒答或依据换为其他文档);回到文档库**重新上传同一内容** → 新行(新 doc_id)已索引,再问同一问题 → 再次命中(检索恢复)
5. 删除完成后对同一文档再删 → 404 错误提示(模态内呈现)

## 4. 重建索引检查(约 2 分钟)

1. 对「已索引」行点「重建索引」图标 → 请求期间按钮禁用;完成后列表刷新,分块数不变(幂等)
2. 对「解析失败」行(步骤 2.5 造出)点「重建索引」→ 源文件仍解析失败 → **行内**该文档标题下出现红色 caption 错误「文件解析失败:…」,状态徽标仍为「解析失败」
3. 「解析中」状态的文档(如有)重建按钮禁用

## 5. 错误态检查(可选,需动后端,约 2 分钟)

1. 停掉 8000 的 uvicorn → 刷新文档库页 → 列表区红色错误文案「RAG 服务不可达,请稍后重试」
2. 重启 uvicorn → 刷新恢复列表;测完保持「只跑一个 dev server」单实例状态

## 6. 视觉与无障碍(DesignRules 硬规则)

- **375px 窄屏**:表格在容器内横向滚动,页面无整体溢出;模态 ≤ 屏宽(带 16px 外边距)
- **焦点环**:Tab 走查上传区/按钮/图标按钮 → 2px 品牌蓝描边 + 2px 偏移;模态打开时焦点落「取消」
- **动效**:hover ≤150ms 颜色过渡(行/按钮/上传区);骨架脉动为唯一无限动画;无旋转加载图标
- **每屏一个 primary**:页面只有「上传文档」;模态内只有「确认删除」(danger);重建索引/删除为 ghost 图标按钮
- **数字全 mono**(分块数/时间);无 emoji 图标;无聊天流/气泡布局
- **容器宽度**:文档库 1152px 居中(2026-09-09 人拍板)

## 7. 判定标准

- **Blocker(不通过,当场修复)**:页面白屏/500/无响应;上传成功但列表不出现该文档或状态不对;删除未二次确认即生效;删除后文档仍在或计数不减;删除后检索仍命中该文档原文(FR-09 核心口径);删除/重建按钮在无确认的情况下自动触发;上传中出现全局遮罩或整页加载;primary 按钮多于一个(页面与模态内分开计)
- **样式打磨类(记遗留,不阻塞)**:间距/字号微调
- **已知非缺陷,勿当 bug 报**:上传解析为同步等待(数秒内完成,超时由 BFF 120s 兜底);列表为单页拉全(分页 UI 未做,规模 ≤100 篇);解析失败的详细错误在刷新后消失(持久形态 = failed 行 + 重建索引,重建失败时行内错误再次呈现);首次上传后的检索命中需等待该文档索引完成(上传接口返回前已完成)

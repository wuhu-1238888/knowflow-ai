# 产品架构(Product Architecture)

> 版本:v0.1 | 最后更新:2026-09-08
> 对应阶段:Stage 06 产品架构

## 信息架构

```
KnowFlow AI(单页应用,顶部导航)
├── 问答页 /           ← 默认页:问题输入 → 带引用回答 → 来源检视面板(抽屉) → 拒答/冲突呈现
├── 文档库 /           ← 上传(5 种格式)/ 文档列表(状态:已解析/已索引/解析失败)/ 删除 / 重建索引
├── 评测页 /eval       ← 三模式评测:一键运行 → mode×category 指标矩阵 → 运行历史(run 列表)
└── 关于 /             ← 产品说明 + NovaTech 虚构数据声明(synthetic)
```

## 模块划分

| 模块 | 职责 | 消费哪些模块的数据 | 提供哪些数据 |
| --- | --- | --- | --- |
| **【核心数据源模块】知识库文档与索引模块** | 原始文件存储、文档解析(5 种文本格式)、分块、Embedding、向量索引 + 倒排索引的构建与维护 | 无(数据入口) | Document / Chunk / 向量索引 / 倒排索引 |
| 检索服务模块 | 三模式检索:Vector、BM25、Hybrid(RRF 融合)、Rerank 重排、top-k 截断 | 知识库文档与索引模块 | 带分数的 chunk 列表(含来源模式标注) |
| RAG 问答管线模块 | context 组装 → LLM 适配层(可插拔,Mock 默认)→ 回答生成 → citation 编号映射 → 拒答判定 → 冲突检测 | 检索服务模块 | 回答 + citations + no_answer + conflicts |
| 来源检视服务模块 | 按 citation 定位源文档与原文片段,供来源面板展示 | 知识库文档与索引模块、RAG 问答管线模块 | chunk 原文定位结果 |
| 文档管理服务模块 | 上传、列表、状态查询、删除、重建索引 | 知识库文档与索引模块 | 文档列表与状态、删除/重建动作 |
| 评测引擎模块 | 装载评测集 → 三模式运行 → 指标计算(Hit@k/MRR)→ 结果落盘 | 检索服务模块、RAG 问答管线模块、评测集夹具 | 指标矩阵、run 结果 JSON |
| QA 日志服务模块 | 记录每次问答的 query/answer/citations/mode/时间 | RAG 问答管线模块 | 日志记录(审计最小落点) |

## 数据流与联动关系

```
原始文档 ─→ 文档管理服务(上传) ─→ 【核心数据源模块】知识库文档与索引模块
                                      │(解析→分块→Embedding→索引)
                                      ↓
              用户提问 ─→ 检索服务模块(三模式 + Rerank) ─→ RAG 问答管线模块(组装/生成/引用/拒答/冲突)
                                      │                          │
                                      │                          ├─→ 来源检视服务(点开引用核对原文)
                                      │                          └─→ QA 日志服务(落日志)
                                      ↓
              评测引擎模块 ─→ 消费评测集夹具,驱动三模式检索与全链路问答 ─→ 指标矩阵 → eval-results/*.json
```

有向无环;评测引擎只读驱动,不写业务数据(除结果落盘)。

| 竞品 | 核心功能 | 定价 | 目标用户 | AI 能力 | 明显短板(聚焦:引用透明性/拒答/检索质量可验证性) |

| RAGFlow(开源 RAG 引擎) | 深度文档解析(复杂 PDF/表格/版面)、混合检索+重排、**引用可点击定位到原文位置** | 开源免费(Apache-2.0),自托管;建议 8 核 32G 起 | 开发者/有工程能力的企业 | 强(解析与检索精度业内领先;citation 定位是其核心差异点) | 部署运维重;是引擎不是产品,无开箱即用的交互层,需自建应用;检索质量验证依赖使用者自建 |
| Dify(开源 LLM 应用平台) | LLM 应用/Agent/工作流编排平台,知识库为组件之一 | 开源免费(Apache-2.0,多租户 SaaS 受限),自托管;4 核 8G 起 | 开发者/低代码使用者 | 中强(工作流与 Agent 强;RAG 够用但深度一般) | RAG 检索深度与 citation 定位弱于 RAGFlow;定位是平台而非知识问答产品;检索质量验证依赖使用者自建 |

## 差异点(一句话)

> **透明可验证的检索质量**:每条回答强制带来源引用且可定位到原文片段、知识库无答案时明确拒答,并用固定评测集实测对比 Vector / Hybrid / Hybrid+Rerank 三种检索链路——把"检索质量"从营销话术变成可复现的数据。

## 结论

- [x] **卡位明确**:不做大而全的企业搜索(打不过 Glean 的 100+ 连接器),不做平台(不与 Dify 争生态),聚焦"新员工知识获取"这一条纵向场景,把**引用可核对、无答案拒答、检索质量可实测**做深。
- [ ] 蓝海(写下风险)
- [ ] 伪需求(重新审视问题分析)

**附注(诚实表述)**:企业知识 AI 赛道竞争激烈且验证充分(市场不是蓝海),本作品集项目的价值主张是**工程实现深度 + 实证评测 + Trust 机制**的可展示性,而非市场规模。

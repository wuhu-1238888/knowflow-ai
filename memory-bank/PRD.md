# 产品需求文档(PRD)

> 版本:v0.1 | 最后更新:2026-09-08
> 对应阶段:Stage 05 PRD
> P0 范围于本阶段冻结;后续新增需求一律进 P1/P2 或不做清单。

## 功能需求(FR)

| 编号 | 功能 | 描述 | 优先级(P0/P1/P2) | 验收口径 |
| --- | --- | --- | --- | --- |
| FR-01 | 文档上传与解析 | 上传 PDF/Markdown/DOCX/HTML/TXT,提取纯文本(无 OCR) | P0 | 对固定 5 个夹具文档(覆盖 5 种格式)执行解析,输出文本非空且含文档标题;解析单元测试(L1)全绿 |
| FR-02 | 分块与索引 | chunk → Embedding → 写入向量库 + 倒排索引 | P0 | 索引命令跑完:库中 doc 数 = 20 篇夹具数,每篇 chunk 数 > 0;同一文档重复执行幂等(库状态不变) |
| FR-03 | 混合检索(三模式) | 向量 + BM25 关键词 → RRF 融合;支持 vector / hybrid / hybrid_rerank 三模式(2026-09-09 人拍板:问答 UI 不暴露模式切换,系统固定默认 hybrid_rerank;三模式对比作为评测维度在评测页呈现,API 仍支持按模式调用) | P0 | 评测命令对 12 个有答案样例跑三模式;Hybrid+Rerank 模式 Hit@5 ≥ 11/12 且 MRR ≥ 0.8(阈值初值,Stage 08 定稿后回填 PRD) |
| FR-04 | RAG 问答 | 检索 → 组装 context → LLM → 生成带引用回答 | P0 | 14 个固定样例全量:答案要点覆盖率 ≥ 90%;幻觉断言 0 例;输出 schema 校验全通过;生成接口单次 < 15s |
| FR-05 | Citation + 来源可查 | 回答中每条断言带 [n] 引用编号;点击可打开源文档并定位到原文片段 | P0 | 14 样例中每条引用指向被检索 chunk 且与答案要点对应(错误引用 = 失败例);来源面板可点开原文核对 |
| FR-06 | 无答案拒答 | 知识库无答案时返回标准拒答话术,不编造 | P0 | 评测集"知识库无答案"2 例 100% 拒答;其余 12 例 0 误拒 |
| FR-07 | 文档冲突处理 | 多来源口径矛盾时并列呈现双方依据(来源+原文),不替用户选边 | P0 | 评测集冲突类 2 例均检测到冲突并并列呈现双方来源 |
| FR-08 | 评测引擎 | 一键跑三模式评测,输出 mode×category 指标矩阵 | P0 | 一条命令跑完 12 例 × 3 模式,输出指标矩阵 JSON;同参数重跑数值一致(可复现) |
| FR-09 | 文档管理 | 列表/状态/删除/重建索引 | P1 | 删除后库中 doc 数减 1 且该文档不再被检索命中;重建索引后命中恢复 |
| FR-10 | QA 日志 | 记录 query/answer/citations/mode/时间 | P1 | 每次问答落一条日志,含 citations 数组(ToB 审计最小体现) |
| FR-11 | 重新生成 | 同一问题重新生成回答,保留历史可见 | P1 | 点重新生成后输出为新回答,旧回答仍可见 |
| FR-12 | 复制回答 / 反馈 | 一键复制回答文本;回答反馈(有用/无用) | P2 | 复制内容与界面所见一致;反馈可记录并落库 |

辅助场景(内部技术支持)共用 FR-01~FR-08,不新增 FR。

## 非功能需求(NFR)

| 类别 | 要求 | 可判定口径 |
| --- | --- | --- |
| 性能 | 本地环境响应快 | 检索接口 < 3s;生成接口单次 < 15s;单文档解析 < 30s;评测全量(12 例 × 3 模式) < 10 分钟 |
| 安全 | 演示数据与密钥隔离 | 演示文档全部标注 `synthetic: true`;API Key 只走 `.env` 不入库;服务本地绑定不暴露公网 |
| 兼容 | 现代浏览器 + 小屏可用 | Chrome/Edge 最新版正常;375px 无横向溢出 |
| 可维护 | 评测可复现、工程可读 | 评测同参数重跑数值一致;LLM Mock 先行(零 Key 跑通全链路);commit 遵循 conventional 规范;文档中文 |

## 明确不做清单

| 项 | 来源 | 理由 |
| --- | --- | --- |
| Multi-Tenant 多租户 | vision 边界 | MVP 单租户演示足够;Future Expansion |
| 角色权限矩阵 / RBAC / SSO | vision 边界 + 问题分析已排除 | 虚构单租户数据无真实组织;产品叙述层面区分管理员/普通员工,不做真实权限控制;Future Expansion |
| 复杂组织架构与审批流 | vision 边界 | 无真实决策链;Future Expansion |
| Agent / Multi-Agent 自主任务 | vision 边界 | 核心价值是检索质量而非自主规划;Future Expansion |
| Memory 会话记忆 | vision 边界 + 问题分析已排除 | 无状态问答即可验证核心闭环;Future Expansion |
| Tool Calling | vision 边界 | 产品无外部动作面;Future Expansion |
| 多模态 RAG / OCR | vision 边界 | 演示文档限定文本型 5 种格式;Future Expansion |
| 自训练 Embedding / Reranker | vision 边界 | 现成开源模型足够;Future Expansion |
| 企业系统集成(IM/网盘/CRM) | vision 边界 | 零集成保证"克隆即可跑";Future Expansion |
| 接入真实企业数据 | vision 边界 | 作品集使用虚构 NovaTech 数据(synthetic 标注),不描述为真实客户 |
| 复用 CareerOS-AI 产品逻辑/代码/数据 | vision 边界 + 隔离红线 | 项目独立实现 |
| 个性化推荐 / 问答历史智能分析 | 问题分析已排除 | 与核心闭环无关,增加复杂度不增加价值 |

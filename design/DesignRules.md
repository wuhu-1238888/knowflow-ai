# 设计规则(Design Rules)

> 版本:v0.2 | 最后更新:2026-09-11
> 对应阶段:Stage 09 设计系统

本文件定义「必须做 / 禁止做」;DesignSystem.md 定义「系统是什么」。两者分工,铁律:**需要新值先改 DesignSystem.md 再使用**(其 YAML front matter 是单一事实来源)。

## UI 原则(3 条)

1. **知识优先,装饰让位**。每个视觉元素必须能回答「它帮用户更快找到/核对/判断知识了吗」:答案正文永远用阅读级排版(body-lg 16px/1.7),依据与回答同屏并置,数字用等宽等距——装饰性渐变、阴影、动画在 KnowFlow 中没有豁免权。
2. **可信可见**。Trust 机制(引用、来源、拒答、冲突)必须有专属视觉与交互,不能被风格淹没:引用 chip 与依据条目双向联动、拒答中性灰 + 依据 0 条、冲突等权并列——「每条断言都能对到原文」是设计红线。检索分数/阈值属工程调试信息,不进主流程(保留在 API、QA 日志与评测页)。
3. **平静高效**。视觉上体现「确定性 > 智能」:中性灰画布 + 发丝线 + 表面层次,品牌蓝只出现在 4 类位置(主按钮/引用/选中态/焦点态,AI 身份以少量品牌表达),动效 ≤ 200ms 且无内容入场动画。KnowFlow 是给新员工每天用的知识工具,不是营销页。

## 组件使用规则

- **按钮层级**:每屏(可见区域)最多一个 primary;primary 仅用于 4 个动作——提问、上传、运行评测、确认删除(danger)。其余一律 secondary/ghost/icon。
- **引用 chip**:只能渲染规则侧映射的编号;编号必须与依据带一一对应;缺失引用显示灰态不可点,禁止静默丢弃。
- **渐变白名单**:`{colors.ai-gradient}` 仅允许出现在 3 个组件——品牌标记、AI 眉题 8px 圆点、「AI 生成中」胶囊。出现第 4 处即违规。
- **胶囊(pill)白名单**:`{rounded.pill}` 仅属于「AI 生成中」状态胶囊;所有按钮、徽标、chip 一律方形(6px 圆角)。唯一例外:按钮内 16px loading 细环 spinner(圆形边框指示器,非胶囊容器)——DesignSystem 状态规范 loading 行明确允许(2026-09-11 自检确认)。
- **阴影档位**:默认 flat + 发丝线;悬停 `{shadows.hover}`;浮层(抽屉/模态/Toast)才能用 `{shadows.floating}`。禁止自造第四档。
- **动效预算**:颜色/背景 150ms;抽屉 200ms;仅「AI 生成中」胶囊与 Skeleton 占位允许无限循环动画;任何内容块禁止入场动画。
- **徽标语义**:文档状态(已索引 success/解析中 info/解析失败 danger/待索引 neutral)与检索模式(关键词/向量/混合)配色固定,禁止换用、禁止混色。
- **数字**:任何分数、耗时、指标、ID 一律 `{typography.numeric}`(mono + tabular-nums)。
- **图标**:线性几何、1.5px 笔画、16/20px;禁止 emoji、禁止拟物插画;知识内容区禁止纯装饰插画。
- **拒答与冲突样式**:拒答 = 中性灰卡(禁红色);冲突 = 琥珀 + 等权双卡(禁红色、禁胜负标记)。

## 颜色语义(2026-09-11 人拍板:品牌紫 → 品牌蓝)

> 颜色是产品语义,不是装饰。改造只发生在 Token 层:改 DesignSystem front matter → theme.css 映射 → 全站自动生效;任何新页面/新组件按本表选择颜色,禁止凭感觉取色。

| 色系 | 用于(允许) | 不用于(禁止) |
| --- | --- | --- |
| **品牌蓝**(brand-600/700/800/100/50) | ① 主按钮(提问/上传/运行评测);② 引用 chip 与依据编号(可点击的证据入口);③ 选中态(✓ 有用/无用 = 浅蓝底 + 蓝字);④ 焦点态;⑤ AI 身份(AI 眉题点/生成中胶囊/品牌标记);⑥ 链接 | 普通操作按钮(重新生成/复制/有用/无用/查看原文的**默认态**)、导航整块深蓝块、全蓝 Badge、大面积蓝底、蓝紫混色渐变、发光效果 |
| **中性**(surface/hairline/ink) | 页面与卡片底、边框、正文文字、**普通按钮默认态**(白/透明底 + 中性灰边框 + 深灰文字)、普通信息 Badge、导航默认态、拒答卡 | 传达成功/失败/冲突/选中(这些必须用语义色) |
| **琥珀**(warning*) | **仅**文档口径冲突:冲突面板、「口径不一致」徽标 | 系统错误、删除确认(用红);品牌表达(用蓝) |
| **绿**(success*) | 成功/完成:已索引、达标、「已复制」 | 普通操作默认态、品牌表达 |
| **红**(danger*) | 真实错误/破坏性:解析失败、删除、API/解析失败 | 拒答卡、冲突面板、一般「未命中」 |
| **灰**(ink-disabled/禁用底) | 禁用/不活跃:禁用按钮、占位符、引用缺失 chip | 表达有信息(次级信息用 ink-3) |

- 普通按钮默认中性,**状态变化才变色**:有用点击后 → 蓝选中;复制 → 绿「已复制」;重新生成中 → 中性加载;失败 → 红。不点击时它们只是中性按钮。
- 检索模式/来源徽标(mode-*)是固定语义色,不适用「普通 Badge 中性化」:关键词 = 石板、向量 = 青、混合 = 品牌深档蓝(当前默认策略)。
- 完整职责表在 DesignSystem.md「色彩语义」节;两文件冲突时以 DesignSystem.md front matter 与职责表为准。

## 逐页页面规则

### 问答页 /(默认页)
- 目标:提问 → 得到带引用的回答 → 当场核对原文(≤ 5 分钟闭环的主要舞台)。
- 必备区块:页头(标题「知识问答」+ 副标题「企业知识助手,基于企业知识库回答问题」)→ 提问区(AskTextarea + primary 提问按钮 + 2–3 个示例问题 chip,示例来自评测集)→ 结果区(AnswerSheet / 拒答卡 / 冲突面板三选一)。
- 交互:Enter 提问、Shift+Enter 换行、`/` 聚焦输入框;点引用 chip 滑出来源抽屉。
- 垂直节奏(2026-09-09 人拍板):主内容顶部呼吸空间 24px(<1024px)/48px(≥1024px),页头 → 提问区 24px,各状态区块间统一 24px;加载/空态/回答/拒答/错误状态同位不跳动;禁止 Hero 式大留白。
- 页面专属禁令:禁止把问答渲染成聊天流/气泡;禁止历史会话时间轴(无状态问答,MVP 无 Memory);**禁止暴露检索策略切换或任何 RAG 技术操作项(2026-09-09 人拍板:系统固定使用默认策略 Hybrid + Rerank,三模式对比只出现在评测页);禁止在元信息行/拒答卡展示工程调试值(最高分、耗时、分数阈值)**。

### 文档库页 /documents
- 目标:上传解析 5 种格式、查看状态、删除/重建索引(FR-01/09)。
- 必备区块:页头(标题「文档库」+ primary 上传按钮)→ UploadZone → 文档表格(标题/格式/状态/分块数/时间/操作)。
- 交互:删除必须走 danger 确认模态(二次确认);上传中行内进度,无全局遮罩。
- 页面专属禁令:禁止自动删除/自动重建索引(须人显式触发)。

### 评测页 /eval
- 目标:一键跑三模式、看指标矩阵、核对数据来源(FR-08 与诚信规则);回答「为什么默认 Hybrid + Rerank」。
- 必备区块:检索策略对比(三模式 × 指标矩阵,当前为实测静态快照版,2026-09-09 提前切片;3.3.4 补齐页头「运行三模式评测」primary + 运行状态)→ EvalMatrix → RunList(运行历史)→ 数据来源页脚 caption。
- 交互:运行中按钮禁用 + Skeleton;点击 run 行展开 per-case 明细。
- 页面专属禁令:禁止手填/预估任何指标数字;矩阵每一格必须能回溯到 run JSON(页脚标注 run-id 与 params_hash)。

### 关于页 /about
- 目标:产品说明 + NovaTech 虚构数据声明。
- 必备区块:定位一句话 → synthetic 声明卡(中性卡片,正文级排版)→ 技术栈列表(mono)→ 边界说明(不做清单摘要)。
- 页面专属禁令:禁止将 NovaTech 描述为真实企业客户或真实商业项目。

### 页面容器宽度(2026-09-09 人拍板)

- 原则:「宽幅居中 + max-width 封顶」——内容居中、按内容类型分档给宽、桌面端利用横向空间;禁止全宽 Dashboard、禁止内容贴近侧栏、禁止为填满空间添加无意义组件。
- 分档(app-shell 按首段路由映射,DesignSystem `containers`):知识问答 960px;评测 1152px;文档库 1152px;关于 880px;未登记路由回落 960px。
- 页内统一:同一页面页头/输入区/卡片/表格共用容器宽度,禁止区块级另设 max-width(明确信息层级理由除外)。
- 响应式:≥640px 左右 padding 24px;<640px 16px;375px 无横向溢出;1920px 内容不拉伸。
- 变更纪律:改宽度 = 先改 DesignSystem `containers` → 再改 app-shell 映射 → 跑 L1 对拍;禁止绕过 token 在页面内硬编码容器宽度。

## 禁止事项(可 grep 检查)

- 禁止硬编码色值(检查:`grep -rn '#[0-9a-fA-F]\{3,8\}' src/`,透明 rgba 与 DesignSystem 内除外)
- 禁止恢复旧品牌紫(检查:`grep -rn '5B5BD6\|4949C4\|3B3BAD\|ECEBFF\|F6F6FF\|8B7CF0' src/ design/DesignSystem.md`——2026-09-11 改造前色值,theme.css 映射层同样禁止)
- 禁止蓝紫混色渐变;渐变仅限 `{colors.ai-gradient}` 一处定义(检查:`grep -rn 'gradient' src/`)
- 禁止普通操作按钮(重新生成/复制/有用/无用/查看原文)默认态使用品牌蓝——默认一律 Neutral,状态变化才变色(有用选中 → 蓝、复制成功 → 绿、失败 → 红)
- 禁止使用 DesignSystem.md front matter 之外的色值/字号/圆角/阴影/动效时长
- 禁止渐变出现在品牌标记、AI 眉题点、生成中胶囊之外(检查:`grep -rn 'gradient' src/`)
- 禁止胶囊(pill)形状用于「AI 生成中」之外的任何组件(检查:`grep -rn '999' src/` 或 `rounded-full`;唯一例外 = 按钮内 16px loading 细环 spinner,见组件使用规则)
- 禁止把回答渲染为聊天气泡、左右对话流或历史时间轴
- 禁止为内容块添加入场动画(fade/slide/scale);瞬时动效总时长 > 200ms(生成中胶囊与 Skeleton 占位脉动除外)
- 禁止阴影超过 `{shadows.floating}` 档、禁止连续多层阴影
- 禁止拒答卡使用 danger 色;禁止冲突面板使用 danger 色或在双卡间设置胜负标记
- 禁止用 emoji 作为 UI 图标;禁止在知识内容区放纯装饰插画
- 禁止同屏出现 > 2 种彩色强调(brand + 1 语义色;状态徽标按其语义色计入 1 类)
- 禁止数字单元格使用非 tabular-nums 字体(检查:数字列未用 `numeric` token)
- 禁止在非 4px 网格的间距上造新值(唯一例外:2px 细间距)
- 禁止为「高级感」添加任何渐变/阴影/动效——每个视觉决策必须能在「UI 原则」中找到产品价值依据
- 禁止暗色模式(本期不做,记 Future Expansion)
